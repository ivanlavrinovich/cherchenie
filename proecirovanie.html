1. Методы проецирования

  • Центральное — лучи выходят из одной точки. Используется в перспективе.
  • Параллельное — лучи параллельны. Бывает косоугольным и прямоугольным.
  • Ортогональное (прямоугольное) — основной метод технического черчения. Лучи перпендикулярны плоскости проекций.

2. Метод Монжа

Пространство делят на три взаимно перпендикулярные плоскости:

  • V — фронтальная;
  • H — горизонтальная;
  • W — профильная.

Их пересечения — оси X, Y, Z. Точка в пространстве задаётся координатами A(x, y, z). На комплексном чертеже получают три проекции:

  • фронтальную A';
  • горизонтальную A;
  • профильную A''.

Связь проекций обеспечивается линиями связи.

3. Проекции точки

Любая точка пространства однозначно определяется тремя координатами. На комплексном чертеже её три проекции связаны между собой линиями связи, перпендикулярными осям.

4. Виды на чертеже

По ГОСТ 2.305 основных видов шесть: главный, сверху, слева, справа, снизу, сзади. Главный вид — самый информативный, его ставят на первое место.

5. Проецирование геометрических тел

  • Многогранники: призма, пирамида.
  • Тела вращения: цилиндр, конус, шар, тор.

Находят проекции точек на поверхности. Для этого используют вспомогательные линии: образующие, окружности, рёбра.

6. Чтение чертежа

Чтение — это мысленное воссоздание формы предмета по проекциям. Порядок:

  1. Прочитать основную надпись.
  2. Определить количество изображений.
  3. Выделить главный вид.
  4. Проанализировать форму по проекциям.
  5. Учесть разрезы и сечения.
  6. Проверить размеры и условности.
Итог: проекционное черчение — ядро инженерной графики. Оно превращает пространственный объект в систему плоских проекций.
