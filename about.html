Главная / О проекте

«Черчение» — это электронное методическое пособие для школьников, изучающих черчение. Сайт создан как учебный проект ученика 10 «А» класса.

1. Что это за сайт

Это онлайн-пособие, в котором собрана вся теория по школьному курсу черчения — от простейших геометрических элементов до чтения сборочных чертежей. Материал разбит по разделам, к каждому есть наглядные иллюстрации, таблицы и алгоритмы построения.

2. Для кого

  • Для школьников, которые изучают черчение.
  • Для тех, кто готовится к контрольным и графическим работам.
  • Для тех, кому нужно быстро найти нужную тему или правило.

3. Что внутри

Раздел Что изучается
01. Основные правила оформленияФорматы, линии, шрифт, размеры, масштабы
02. Геометрические построенияДеление на равные части, сопряжения
03. Прямоугольное проецированиеМетод Монжа, виды, проекции
04. Аксонометрические проекцииИзометрия, диметрия
05. СеченияВиды сечений, обозначение, штриховка
06. РазрезыПростые и сложные разрезы
07. Типовые соединенияРезьбовые, сварные, шпоночные

Дополнительно на сайте есть три мини-игры для самопроверки и личный кабинет со статистикой прогресса.

4. Как сделано

Сайт построен на чистом HTML, CSS и JavaScript — без использования сторонних фреймворков и систем управления контентом. Это значит:

  • все страницы — это отдельные файлы с разметкой;
  • оформление — в одном файле стилей;
  • логика игр, прогресса и профиля — на JavaScript;
  • хостинг — GitHub Pages (бесплатно, доступно по всему миру).

5. Приватность

Сайт не собирает персональные данные. Для профиля используется только псевдоним (ник) и пароль, причём пароль хранится в виде необратимого хеша. Прогресс, аватарка и достижения находятся только в браузере пользователя и никуда не передаются.

Подробнее — на странице Политика конфиденциальности.

6. Планы развития

  • Расширение теории по всем разделам.
  • Добавление новых иллюстраций и схем.
  • Больше практических заданий и примеров.
  • Развитие мини-игр и системы достижений.
